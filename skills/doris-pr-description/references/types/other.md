# Other

Title tag: `other`. Use only when no other type fits. Most such PRs are experiments, placeholders, or CI trials that are not meant to be merged; open those as Draft PRs (`gh pr create --draft`), so reviewers know to skip them.

If the PR is meant to be merged and still fits no type, explain why in Why Other; the PR type list may need a new entry.

## Background

The context the experiment or placeholder needs, in one or two sentences.

## Details

- **Why Other** (required): why no other type fits. For an experiment, what it tests and when it will be closed. If you think a new PR type is needed, say which.

The other sections are still required, but one line each is enough.
